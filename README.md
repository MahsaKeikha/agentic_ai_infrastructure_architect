# F40 Agentic AI Infrastructure Architect

Standalone multi-agent reference implementation for AI infrastructure architecture, capacity planning, platform reliability, cost governance, and deployment readiness.

Visible executable modules are exposed directly in `AGENTS/`, `TOOLS/`, and `SKILLS/`.

Run with `python run.py` and validate with `pytest -q`.
